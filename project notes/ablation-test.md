## Limitations and confounds

**Self-enhancement risk (E1).** The frozen criteria were generated by claude-opus-4-8 during the baseline run, so in E1 Opus scores against criteria produced by its own model family while gpt-5-5 and gemini-3-1-pro score against another family's criteria.
This is the price the design pays for isolating stage 2; a judge disagreement in E1 can reflect either scoring behaviour or affinity with the criteria's phrasing.

**Sampling configuration is not constant across judges (E1).** Anthropic deprecated the temperature parameter on Opus 4.7+, and the man.ai client drops it for claude-opus-4-8 before the request is sent.
The engine asks for temperature=0 on every judge call; per-call sampling_params_sent fields in the jsonl records show what actually left the process:

- claude-opus-4-8: {"model": "claude-opus-4-8", "n": 1}
- gemini-3-1-pro: {"model": "gemini-3-1-pro", "n": 1, "temperature": 0.0}
- gpt-5-5: {"model": "gpt-5-5", "n": 1, "temperature": 0.0}

So sd_repeat measures sampling variance for claude-opus-4-8 (no temperature control) and residual nondeterminism under greedy decoding for gpt-5-5 and gemini-3-1-pro.
Those are different quantities, which is why sd_repeat is also reported per judge rather than only pooled.
E1 holds judge identity as the variable of interest but cannot hold sampling configuration constant, because one model in the lineup has no temperature knob.

**Range restriction.** 84% of baseline gradings sit at raw 9 or 10, so the per-test signal is compressed near the top of the scale; correlation-style statistics are avoided for this reason.

**Sample size.** 3 repeats per cell bounds how finely sd_repeat is estimated; a per-cell sd from 3 draws is itself noisy.

**Baseline sd = 0 read as saturation.** The baseline judge sampled freely (no temperature control), so the 9 tests holding sd = 0 across 8 repeats indicate score saturation rather than deterministic decoding.
